# Installation Process

1. Download the Alpine Linux Extended ISO from the [website](https://alpinelinux.org/downloads/).
2. Plug in your USB drive and format the new ISO image onto it.
3. Go into the BIOS and set the USB drive to be first in the boot order.
4. Reboot into the USB drive.
5. Install Alpine Linux with the installation script ([install-alpine.sh](../scripts/install-alpine.sh)).
6. Reboot into the newly loaded Alpine Linux system.
7. Once in the Alpine Linux system, run the setup script ([setup-alpine.sh](../scripts/setup-alpine.sh)).
