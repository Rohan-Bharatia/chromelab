# 💻 chromelab 💻

A documented process of turning my old [Acer ChromeBook Spin 11](https://www.amazon.com/Acer-Chromebook-CP311-1H-C5PN-Convertible-Celeron/dp/B07G4CWK1D) into a fully functional homelab.

## 🧰 Requirements

1. A functional laptop
2. A bootable USB drive
